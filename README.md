# Simple Java Docker

A simple Java application containerized using Docker as part of my Docker learning journey.

## What I Learned

- Docker basics
- Docker Images and Containers
- Dockerfile
- `FROM` instruction
- `WORKDIR` instruction
- `COPY` instruction
- `RUN` instruction
- `CMD` instruction
- Building a Docker image
- Running a Docker container

## Technologies Used

- Java
- Docker
- Dockerfile


## Docker Workflow

Dockerfile
    ↓
    
docker build
    ↓
    
Docker Image
    ↓
    
docker run
    ↓
    
Docker Container
    ↓
    
Java Application


## Learning Purpose

This project was created to practice Docker fundamentals and understand how a Java application can be packaged and executed inside a Docker container.

More Docker concepts and projects will be added as I continue learning.
